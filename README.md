# Nicolas Nassar

Estudante de Engenharia de Software na Universidade Positivo (Curitiba, formatura prevista em 2029), em busca de estágio em desenvolvimento de software com foco em IA e automação.

Construo projetos que funcionam de ponta a ponta e deixo tudo documentado: de um sistema de gestão para barbearia publicado online a uma triagem de currículos com IA integrada a Gmail e Telegram. Meu diferencial é transformar uma ideia em solução rodando, com README claro, modelagem (BPMN, UML, C4) e integração com APIs de IA.

## Habilidades e tecnologias

- **Linguagens:** Python, JavaScript, HTML e CSS
- **Ferramentas:** n8n, Git e GitHub (GitHub Pages), integração de APIs (Gmail, Telegram Bot, Google Sheets, OCR.space), Google Gemini com saída estruturada em JSON
- **Competências:** automação de processos, integração de APIs de IA, desenvolvimento web sem frameworks, modelagem de sistemas e documentação técnica
- **Em estudo:** IA aplicada e machine learning com Python, SQL

## Projetos em destaque

### [FadeHouse](https://github.com/Nicolas-JN/fadehouse) — sistema de gestão para barbearia
Aplicação web completa em HTML, CSS e JavaScript puros: agendamento para clientes e painel administrativo com agenda, estoque, faturamento e caixa. [Demo ao vivo](https://nicolas-jn.github.io/fadehouse/)

### [ai-recruiter-n8n](https://github.com/Nicolas-JN/ai-recruiter-n8n) — triagem de currículos com IA
Automação em n8n que recebe currículos por e-mail, extrai o texto do PDF, avalia cada candidato com o Gemini contra critérios configuráveis e permite consultar e gerenciar candidatos por um assistente no Telegram.
